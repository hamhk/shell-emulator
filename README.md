# Эмулятор оболочки ОС (UNIX-подобный shell)

Учебный проект: эмулятор командной строки с виртуальной файловой системой (VFS). Язык: Python 3.10+.

## Запуск

```bash
python3 emulator.py
```

## Статус этапов

| Этап | Название | Статус |
|------|----------|--------|
| 1 | REPL | ✅ готово |
| 2 | Конфигурация | ⏳ в работе |
| 3 | VFS | ⏳ в работе |
| 4 | Основные команды | ⏳ в работе |
| 5 | Дополнительные команды | ⏳ в работе |

## Этап 1. REPL

Минимальный прототип: диалог с пользователем уже работает, большинство команд пока заглушки.

- CLI-приложение, приглашение содержит имя VFS: `[vfs]$ `
- Собственный парсер: кавычки `'...'` (буквально) и `"..."`, экранирование `\`, раскрытие переменных окружения реальной ОС (`$HOME`, `${USER}`); неопределённая переменная даёт пустую строку, как в bash. Упрощение: результат раскрытия не разбивается по пробелам повторно
- Сообщения об ошибках: неизвестная команда, неверные аргументы, ошибка разбора
- Заглушки `ls`, `cd` (выводят своё имя и аргументы)
- Команда `exit`

Пример сессии:

```
[vfs]$ ls -l /tmp
ls: аргументы: ['-l', '/tmp']
[vfs]$ cd $HOME
cd: аргументы: ['/home/user']
[vfs]$ cd a b
Ошибка: cd: слишком много аргументов
[vfs]$ foo
Ошибка: foo: команда не найдена
[vfs]$ exit
```

## Этап 2. Конфигурация

Планируется: параметры командной строки (путь к VFS, путь к стартовому скрипту), отладочный вывод параметров при запуске, выполнение стартового скрипта с остановкой на первой ошибке, тестовые скрипты запуска.

## Этап 3. VFS

Планируется: загрузка VFS из XML (бинарные данные в base64), все операции в памяти, обработка ошибок загрузки, тестовые VFS (минимальная, несколько файлов, 3+ уровня вложенности), общий стартовый скрипт.

## Этап 4. Основные команды

Планируется: реальная логика `ls` и `cd`, новые команды `find` и `du`, стартовый скрипт с примерами всех режимов и ошибок.

## Этап 5. Дополнительные команды

Планируется: `chmod` и `touch` (изменения только в памяти), стартовый скрипт с примерами всех режимов и ошибок.
